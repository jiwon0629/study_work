﻿# 001 — 3D Re-ID 멀티 CCTV 추적 웹앱 설계 총괄

- 날짜: 2026-10-20 생성 · 문서 재구성 2026-10-20
- 채널: #3d-re-id (1562128613648892095)

## 1. 목표

어안 CCTV 다수의 고정 영상 스트림에서 사람·동물·차량을 감지하여 윤곽선으로 개체 특정, 카메라 간 Re-ID로 이어 추적, 현재/과거/미래 예측 경로를 시각화하는 웹앱. 쿼리 이미지/영상 업로드로 타겟 개체를 지정(하이라이트 추적)하는 기능 포함. 이 기능군을 총칭하여 **re-id**라 부른다.

## 2. 파이프라인 아키텍처

1. **전처리 (카메라별 색 보정 + 각도 정규화) — 2026-10-20 확정**
   - 색 보정: 보정 스티커의 표준 색 패치 실츬값 대비 화이트밸런스/감마/채도 보정 행렬을 카메라별 산출, 주기 갱신(일조·구름 그림자 대응) → 상세: 005
   - 각도 정규화: OpenCV fisheye 모델로 어안 왜곡 제거 + 스티커 마커 호모그래피로 시점 보정
2. **감지/분할**: YOLO 계열 + SAM2/YOLO-seg로 윤곽선(마스크) 추출 (animal 클래스 포함 → 004 §1)
3. **단일 카메라 추적**: ByteTrack/BoT-SORT (고정 CCTV, 트랙 오버레이만 이동) + 동반물 링크 추론 → 004 §1.2
4. **카메라 간 Re-ID**: OSNet/Torchre-id(사람)·차량 Re-ID 임베딩 + 코사인 매칭, 카메라 토폴로지·시간 제약 → 팩터 상세: 003
5. **경로 추적**: 픽셀→지도 좌표 투영, Kalman(단기) / Trajectron++ 계열(장기 예측) + occupancy 격자 맵 옵션 → 004 §2
6. **쿼리 타겟**: 업로드 이미지/영상 → 임베딩 매칭 → 개체 하이라이트
7. **웹앱**: WebSocket 실시간 오버레이 + 지도/캔버스 경로 렌더링
