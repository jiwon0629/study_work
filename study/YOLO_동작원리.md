# YOLO 동작 원리 (초보 개발자용)

## 1. YOLO가 하는 일

**객체 탐지(Object Detection)**는 이미지 한 장에서 두 가지를 알아내는 작업입니다.

- **무엇이** 있는지 (클래스: 사람, 자동차, 개 …)
- **어디에** 있는지 (바운딩 박스: x, y, 너비, 높이)

YOLO는 **"You Only Look Once"**, 즉 **이미지를 한 번만 보고** 이 두 가지를 동시에 알아내는 모델입니다.

## 2. YOLO 이전의 방식과의 차이

YOLO 이전에 많이 쓰던 R-CNN 계열은 **2단계(two-stage)** 방식이었습니다.

```
[1단계] "물체가 있을 것 같은 영역" 후보를 약 2,000개 뽑음
[2단계] 후보 영역을 하나씩 잘라서 "이게 뭐지?" 분류
```

정확하긴 하지만 후보마다 판단을 반복해야 해서 **느렸습니다.**

YOLO는 이 과정을 하나로 합쳤습니다.

```
이미지 → 신경망 1번 통과 → 모든 박스 + 클래스가 한꺼번에 나옴
```

그래서 **1단계(one-stage) 탐지기**라고 부르고, 실시간(초당 30프레임 이상) 처리가 가능해졌습니다.

## 3. 핵심 아이디어: 이미지를 격자로 나눈다

원조 YOLO(v1) 기준으로 설명하면 가장 이해하기 쉽습니다.

### ① 이미지를 S×S 격자로 나눔 (예: 7×7)

```
┌──┬──┬──┬──┬──┬──┬──┐
│  │  │  │  │  │  │  │
├──┼──┼──┼──┼──┼──┼──┤
│  │  │개│  │  │  │  │   ← 개의 '중심점'이 이 칸에 있음
├──┼──┼──┼──┼──┼──┼──┤
│  │  │  │  │  │차│  │   ← 자동차의 '중심점'이 이 칸에 있음
└──┴──┴──┴──┴──┴──┴──┘
```

### ② 규칙: "물체의 중심이 들어 있는 칸이 그 물체를 책임진다"

각 칸은 "내 안에 중심이 있는 물체"만 찾으면 됩니다. 탐지라는 큰 문제를 **칸 단위의 작은 문제 49개**로 쪼갠 셈입니다.

### ③ 각 칸이 예측하는 값

각 칸은 박스 B개(v1에서는 2개)를 예측하고, 박스마다 숫자 5개를 출력합니다.

| 값 | 의미 |
|---|---|
| `x, y` | 박스 중심 위치 (그 칸 기준 상대 좌표, 0~1) |
| `w, h` | 박스 너비·높이 (전체 이미지 기준 비율, 0~1) |
| `confidence` | "여기 물체가 있고, 내 박스가 정확하다"는 확신도 |

여기에 더해 각 칸은 **클래스 확률**(개일 확률, 고양이일 확률 …)도 출력합니다.

### ④ 출력 결과는 하나의 큰 숫자 덩어리(텐서)

v1 기준(격자 7×7, 칸당 박스 2개, 클래스 20개):

```
7 × 7 × (2×5 + 20) = 7 × 7 × 30
```

즉 신경망의 최종 출력은 **7×7×30 크기의 숫자 배열** 하나입니다. 이 숫자들을 위 규칙대로 해석하면 박스 목록이 됩니다.

## 4. 신경망 구조: 몸통, 목, 머리

요즘 YOLO는 대부분 다음 세 부분으로 구성됩니다.

```
입력 이미지 (640×640)
     │
 [Backbone] 특징 추출기 — 선, 모서리 → 바퀴, 눈 → 자동차, 얼굴 순으로 점점 추상적인 특징을 뽑음
     │
 [Neck]     여러 크기의 특징을 섞음 — 작은 물체와 큰 물체를 모두 잘 보기 위해
     │
 [Head]     최종 예측 — 박스 좌표 + 클래스 점수 출력
```

비유하자면 Backbone은 "눈", Neck은 "멀리 보기와 가까이 보기를 합치는 과정", Head는 "판단을 내리는 부분"입니다.

## 5. 학습: 무엇을 맞추도록 배우나

정답 라벨(박스 + 클래스)과 모델의 예측을 비교해 **손실(loss)**을 계산하고, 이 값이 줄어들도록 가중치를 조정합니다. 손실은 크게 세 가지입니다.

1. **박스 손실**: 예측한 박스가 정답 박스와 얼마나 어긋났나
2. **객체 존재 손실**: 물체가 있는 칸은 "있다", 없는 칸은 "없다"고 맞혔나
3. **분류 손실**: 클래스를 맞혔나

박스가 얼마나 잘 맞는지는 **IoU(Intersection over Union)**로 측정합니다.

```
IoU = (두 박스가 겹치는 면적) / (두 박스를 합친 전체 면적)

완전히 일치하면 1.0, 전혀 겹치지 않으면 0.0
```

## 6. 추론 후처리: 같은 물체에 박스가 여러 개 생기는 문제

모델은 한 물체에 대해 비슷한 박스를 **여러 개** 내놓기 쉽습니다. 그래서 두 단계로 정리합니다.

**① 신뢰도 필터링:** 점수가 낮은 박스(예: 0.25 미만)는 버립니다.

**② NMS(Non-Maximum Suppression, 비최대 억제):**

```
1. 남은 박스를 점수 높은 순으로 정렬
2. 1등 박스를 확정
3. 1등과 IoU가 높은(예: 0.45 이상) 박스 = "같은 물체를 본 중복"이므로 삭제
4. 남은 박스로 2~3을 반복
```

```
NMS 전:  개 [0.92] [0.85] [0.71]   ← 같은 개에 박스 3개
NMS 후:  개 [0.92]                 ← 하나만 남음
```

> **참고:** "YOLO가 1차 탐지, VLM이 2차 검증" 구조에서 VLM은 바로 이 단계 다음에 붙습니다. 걸러진 박스들을 VLM이 한 번 더 확인하는 방식입니다.

## 7. 버전별 주요 개선점

v1의 약점은 **칸 하나가 물체 하나만 담당할 수 있어서** 작은 물체나 붙어 있는 물체를 잘 못 찾는다는 점이었습니다. 이후 버전들은 이 약점을 줄이는 방향으로 발전했습니다.

| 버전 | 핵심 변화 |
|---|---|
| v2 | **앵커 박스** 도입: 미리 정해 둔 박스 모양(세로로 긴 것, 가로로 긴 것 등)을 기준으로 "얼마나 조정할지"만 예측하게 함 |
| v3 | **3가지 크기의 격자**로 동시에 예측: 작은 격자는 큰 물체, 촘촘한 격자는 작은 물체 담당 |
| v5 / v8 | 사용하기 쉬운 프레임워크(Ultralytics). v8은 앵커 없이(**anchor-free**) 박스를 직접 예측 |
| v10 이후 | 학습 방식을 바꿔 **NMS 없이도** 중복 박스가 생기지 않게 함 → 더 빠름 |

예를 들어 YOLOv8에서 640×640 이미지를 넣으면 80×80, 40×40, 20×20 세 격자에서 총 **8,400개**의 후보를 예측하고, 이를 필터링해서 최종 결과를 냅니다.

## 8. 실제 코드 예시

```python
from ultralytics import YOLO

model = YOLO("yolov8n.pt")            # 사전학습 모델 불러오기
results = model("street.jpg", conf=0.25, iou=0.45)  # conf: 신뢰도 기준, iou: NMS 기준

for box in results[0].boxes:
    cls_name = model.names[int(box.cls)]
    print(cls_name, float(box.conf), box.xyxy.tolist())  # 클래스, 점수, 좌표
```

내부에서는 앞에서 설명한 **격자 예측 → 신뢰도 필터 → NMS**가 모두 실행됩니다.

## 한 줄 요약

> YOLO는 **이미지를 격자로 나누고**, 각 칸이 **"내 안에 중심이 있는 물체의 박스와 클래스"**를 예측하게 한 뒤, 신경망을 **한 번만 통과시켜** 모든 결과를 얻고 **NMS로 중복을 정리**하는 모델입니다.
