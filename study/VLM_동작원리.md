# VLM 동작 원리 (초보 개발자용)

## 1. VLM이란

**VLM(Vision-Language Model, 시각-언어 모델)**은 **이미지와 글을 함께 입력받아 글로 답하는 모델**입니다. GPT-4o, Gemini, Claude, Qwen-VL, LLaVA 같은 모델이 여기에 해당합니다.

```
입력:  [사진] + "이 사진에서 안전모를 안 쓴 사람이 있어?"
출력:  "네, 왼쪽에 서 있는 사람이 안전모를 쓰지 않았습니다."
```

YOLO와 비교하면 차이가 분명합니다.

| | YOLO | VLM |
|---|---|---|
| 출력 | 박스 좌표 + 정해진 클래스 번호 | 자유로운 문장 |
| 알아보는 대상 | 학습한 클래스만(예: 80개) | 사실상 제한 없음 |
| 질문 | 받지 않음 | 무엇이든 질문 가능 |
| 속도 | 수 ms | 수백 ms ~ 수 초 |
| 강점 | 정확한 위치, 빠른 속도 | 맥락 이해, 세부 판단, 추론 |

## 2. 핵심 아이디어: 이미지를 "단어처럼" 바꿔서 LLM에 넣는다

VLM의 기본 발상은 간단합니다.

> 이미 글을 잘 이해하는 **LLM(대규모 언어 모델)**이 있으니, **이미지를 LLM이 읽을 수 있는 형태로 번역**해서 넣어 주자.

그래서 대부분의 VLM은 세 부품으로 구성됩니다.

```
  [이미지]                           [질문 텍스트]
     │                                    │
┌────▼─────────┐                          │
│ ① 비전 인코더 │  이미지 → 특징 벡터       │
└────┬─────────┘                          │
┌────▼─────────┐                    ┌─────▼─────┐
│ ② 프로젝터    │  "LLM 언어"로 변환   │ 토크나이저 │
└────┬─────────┘                    └─────┬─────┘
     │      이미지 토큰 + 텍스트 토큰      │
     └──────────────┬─────────────────────┘
              ┌─────▼─────┐
              │  ③ LLM    │  한 단어씩 답변 생성
              └─────┬─────┘
                    ▼
            "네, 왼쪽에 서 있는 사람이…"
```

## 3. 부품 ①: 비전 인코더 — 이미지를 조각내서 읽기

대부분 **ViT(Vision Transformer)**를 사용합니다.

**단계 1. 이미지를 작은 정사각형 조각(패치)으로 자릅니다.**

```
336×336 이미지를 14×14 픽셀 패치로 자르면
→ 가로 24개 × 세로 24개 = 576개 패치
```

**단계 2. 각 패치를 숫자 벡터로 바꿉니다.** 문장을 단어로 나누는 것처럼, 이미지를 "시각 단어"로 나누는 셈입니다.

**단계 3. 트랜스포머가 패치끼리 서로 참고하게 합니다(Attention).** "이 패치는 바퀴 같고, 옆 패치는 차 문 같으니, 둘이 합쳐 자동차"처럼 **패치 사이의 관계**를 파악해, 각 패치 벡터에 주변 맥락이 담기게 됩니다.

### 비전 인코더는 어떻게 "의미"를 배웠나: CLIP

많은 VLM이 **CLIP** 방식으로 미리 학습된 인코더를 가져다 씁니다. CLIP은 인터넷의 **(이미지, 설명 문장) 쌍 수억 개**로 학습합니다.

```
[강아지 사진]  ↔  "잔디밭 위의 강아지"     → 벡터를 서로 가깝게
[강아지 사진]  ↔  "빨간 스포츠카"          → 벡터를 서로 멀게
```

그 결과 비전 인코더는 **이미지를 "의미가 담긴 벡터"로** 바꿀 수 있게 됩니다. YOLO처럼 "클래스 번호 17"이 아니라, 언어와 연결된 풍부한 의미입니다.

## 4. 부품 ②: 프로젝터 — 통역사

비전 인코더의 벡터와 LLM이 쓰는 단어 벡터는 **크기도, 의미 공간도 다릅니다.** 프로젝터는 작은 신경망(보통 2층 MLP)으로, 이미지 벡터를 **LLM의 단어 벡터와 같은 공간으로 변환**합니다.

```
이미지 패치 벡터 (1024차원)  → 프로젝터 →  "LLM 단어"처럼 생긴 벡터 (4096차원)
```

이 과정을 거치면 LLM 입장에서는 이미지가 **"576개의 낯선 단어로 된 문장"**처럼 보입니다.

## 5. 부품 ③: LLM — 읽고 답하기

LLM에 들어가는 입력은 이런 모양입니다.

```
[이미지토큰1][이미지토큰2]…[이미지토큰576] "이 사진에서 안전모를 안 쓴 사람이 있어?"
```

LLM은 이 전체를 읽고 **다음 단어를 하나씩 예측**하며 답을 만듭니다(자기회귀 생성).

```
"네" → "네," → "네, 왼쪽에" → "네, 왼쪽에 서 있는" → …
```

질문 속 "안전모"라는 단어가 Attention을 통해 **안전모와 관련된 이미지 토큰에 주목**하게 되고, 그래서 이미지 속 특정 부분에 대해 답할 수 있습니다.

## 6. 학습 과정: 보통 두 단계

**1단계 — 정렬(Alignment) 학습**

- 비전 인코더와 LLM은 고정하고 **프로젝터만** 학습합니다.
- 데이터: (이미지, 캡션) 쌍
- 목표: 이미지 토큰을 LLM이 이해할 수 있게 "통역"하는 법 배우기

**2단계 — 지시 학습(Instruction Tuning)**

- 프로젝터와 LLM(경우에 따라 인코더까지)을 함께 학습합니다.
- 데이터: (이미지, 질문, 모범 답변) — "이 차트에서 최댓값은?", "사진 속 사람 수는?" 등
- 목표: 질문을 따라 대화하듯 답하는 법 배우기

의료·산업 분야에 쓸 때는 여기에 **3단계: 도메인 데이터로 미세조정**을 추가하는 경우가 많습니다.

## 7. VLM의 약점

### ① 정확한 위치 찾기에 약함

이미지를 14×14 패치로 쪼개 "의미" 위주로 처리하기 때문에, 픽셀 단위의 정확한 좌표를 내는 것은 YOLO보다 서툽니다. 최근 모델(Qwen-VL, Florence 등)은 좌표를 텍스트로 출력할 수 있지만, 정밀도와 속도는 여전히 전용 탐지기에 못 미칩니다.

### ② 작은 물체를 놓침

입력 해상도가 제한되어 있어, 큰 이미지를 줄이면 작은 물체는 패치 하나보다도 작아져 사라집니다.

### ③ 환각(Hallucination)

LLM은 "그럴듯한 다음 단어"를 생성하는 구조라, **없는 물체를 있다고 말할** 수 있습니다. 예를 들어 주방 사진이면 실제로는 없는 "냉장고"를 언급하기도 합니다.

### ④ 느리고 무거움

수십억 개의 파라미터에 이미지 토큰 수백 개를 처리하고, 답도 한 단어씩 만들어야 합니다.

## 8. YOLO + VLM 조합이 잘 맞는 이유

두 모델의 강점과 약점이 서로 정확히 보완됩니다.

```
YOLO:  위치 정확 O  빠름 O    |  세부 판단 X  맥락 이해 X
VLM:   위치 부정확 X 느림 X   |  세부 판단 O  맥락 이해 O
```

그래서 효과적인 구조는 이렇습니다.

```
1. YOLO가 전체 이미지에서 빠르게 후보 박스를 찾음      (위치는 YOLO 담당)
2. 애매한 박스만 잘라서(crop) VLM에 전달               (VLM 호출 최소화)
3. VLM에게 "이 이미지에 OO가 있나? 예/아니오로 답해"   (판단은 VLM 담당)
```

박스를 잘라서 보내는 방식은 VLM의 약점도 함께 해결해 줍니다.

- **작은 물체 문제:** 잘라낸 영역이 확대되어 들어가므로 해결됩니다.
- **환각:** 범위가 좁은 예/아니오 질문이라 크게 줄어듭니다.
- **속도:** 이미지 전체가 아니라 일부 박스만 처리하므로 개선됩니다.

## 9. 코드 예시

```python
from transformers import pipeline

vlm = pipeline("image-text-to-text", model="Qwen/Qwen2.5-VL-3B-Instruct")

messages = [{
    "role": "user",
    "content": [
        {"type": "image", "url": "crop_from_yolo.jpg"},   # YOLO 박스를 잘라낸 이미지
        {"type": "text", "text": "이 사람이 안전모를 쓰고 있나요? '예' 또는 '아니오'로만 답하세요."},
    ],
}]

out = vlm(text=messages, max_new_tokens=5)
print(out[0]["generated_text"][-1]["content"])   # → "아니오"
```

내부에서는 **이미지를 패치로 분할 → 비전 인코더 → 프로젝터 → 질문 토큰과 결합 → LLM이 "아니오" 생성** 순서로 동작합니다. (모델이나 라이브러리 버전에 따라 입력 형식이 조금 다를 수 있습니다.)

## 한 줄 요약

> VLM은 **이미지를 패치로 잘라 "시각 단어"로 바꾸고**, 이를 **프로젝터로 LLM의 언어 공간에 번역**한 뒤, **LLM이 질문과 함께 읽고 답을 한 단어씩 생성**하는 모델입니다.
