## 5. Market-1501 정량 평가 1차 결과 (2026-10-20)

- 데이터: Market-1501 원본(HF Lekim89/market1501 미러), train split pid 100명 1,046장, 같은 pid 타카메라 이미지를 정답으로 하는 축소 프로토콜
- 임베딩: OSNet x1.0 + msmt17 가중치 (HF aveocr 미러에서 확보 — 008 §2의 gdown 문제 해소)
- **결과: Rank-1 68.6% / mAP 53.1%** (축소 프로토콜 — 공식 19k 갤러리 프로토콜과 수치 직접 비교 불가)

- 임계값 트레이드오프 (이후 토폴로지·시간·배타성 게이트가 false 추가 차단):

|---|---|---|
| 0.55 | 0.951 | 0.214 |
| 0.60 | 0.884 | 0.107 |
| 0.65 | 0.779 | 0.047 |

- **판정: 카메라 간 개체 특정은 현재 스택으로 정량적으로 동작.** 운영 기본값 th=0.60 권장(리콜 우선, 나머지 게이트가 오탐 차단), 보안 강화 환경은 0.65

## 6. AI City 실측 2카메라 라이브 데모 (2026-10-20)

- 데이터: AI City 2024 test (AMAGI 물류 사이트), 동일 현장 4카메라 동기화 72초
- 데모: c1(Camera1_0) + c4(Camera2_5), 960×540 감지, 트랙별 1회 매칭 설계
- **결과: 카메라 내 ID 안정(오병합·파편화 없음). 카메라 간 동일 인물 전이 장면은 이 클립에서 미캡처**
- 교훈:
  - 전수 스캔식 "순차 매칭"은 오래된 sighting이 20초간 유효해 오탐 전이를 양산 — 라이브 파이프라인(트랙별 1회 매칭 + 배타성)이 정답
